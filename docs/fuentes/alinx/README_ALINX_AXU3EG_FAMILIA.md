# AXU3EG: notas del README oficial de ALINX

**Fuente:** [README.md publicado en el repositorio oficial de ALINX](https://github.com/alinxalinx/AXU2CG-E_AXU3EG_AXU4EV-E_AXU5EV-E/blob/master/README.md). Esta página es una síntesis en español con atribución y enlace al original; no es una copia literal.

El repositorio reúne un proyecto de demostración para la familia AXU2CG-E/AXU3EG/AXU4EV-E/AXU5EV-E y declara **Vivado 2020.1** como requisito. Describe conectores USB 3.0, dos Ethernet (PS y PL), UART de PS y PL, microSD, dos headers de expansión de 40 pines, CAN, RS485, MIPI, LEDs y botones. Para los headers, indica alimentación de 5 V/3.3 V, tierras y señales de PL de 3.3 V.

## Cómo usar esta referencia

Es una página de familia y un demo antiguo. Ayuda a reconocer la intención del diseño de fábrica, pero no demuestra compatibilidad directa con AXU3EGB, Vivado 2026.1, EDF 26.06 ni con el bitstream que está instalado en la placa. Contrastar los pines con el [manual específico AXU3EGB](AXU3EGB_User_Manual_ALINX.pdf) y revisar cada proyecto antes de migrarlo.

La guía del fabricante se mantiene en [GitHub ALINX](https://github.com/alinxalinx/AXU2CG-E_AXU3EG_AXU4EV-E_AXU5EV-E). La lámina de pines del proyecto utiliza el manual AXU3EGB más específico.
